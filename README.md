# TorneoApp

App móvil para gestión de torneos deportivos amateurs.

## Requisitos

- Node.js 18+
- Expo CLI (`npm install -g expo-cli`)
- App Expo Go en el celular (iOS/Android)

## Instalación

```bash
git clone <repo>
cd torneoapp
npm install
```

## Correr el proyecto

```bash
npx expo start
```

Escaneá el QR con Expo Go.
